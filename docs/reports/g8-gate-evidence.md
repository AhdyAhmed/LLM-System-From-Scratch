# Phase 8 — Gate G8 Evidence Report (Day071–Day080)

## 1. Executive Summary

Phase 8 (**Document ingestion and retrieval with inspectable citations**, Day071–Day080) is complete and verified against Gate **G8**:
- **Self-Authored Corpus & 32-Question Retrieval Benchmark (`Day071`):**
  - [`evals/retrieval/corpus_documents.json`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/evals/retrieval/corpus_documents.json) (`6` documents across `workspace-alpha` and `workspace-beta`, including an adversarial prompt-injection document `untrusted-vendor-memo.txt`).
  - [`evals/retrieval/questions_benchmark.json`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/evals/retrieval/questions_benchmark.json) (`32` questions split evenly into `16` development and `16` frozen held-out test queries, covering answerable, unanswerable, and cross-workspace isolation cases).
- **Bounded Upload Storage, Validation & Workspace Access Rules (`Day072`):**
  - [`V4__phase8_documents_retrieval_and_citations.sql`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/backend/src/main/resources/db/migration/V4__phase8_documents_retrieval_and_citations.sql), [`DocumentIngestionAndRetrievalService.java`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/backend/src/main/java/com/scratchllm/platform/documents/DocumentIngestionAndRetrievalService.java), and [`DocumentController.java`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/backend/src/main/java/com/scratchllm/platform/documents/DocumentController.java).
  - Enforces strict path-traversal rejection (`INVALID_FILENAME`), MIME-type allowlisting (`text/plain`, `text/markdown`), `64 KB` upload ceiling (`413 DOCUMENT_TOO_LARGE`), opaque server-generated file keys (`doc-{uuid}-r{rev}.utf8`), and orphan file reconciliation (`reconcileOrphanedUploadFiles()`).
  - Reading and searching are workspace-shared (`OWNER` and `MEMBER`), while deletion requires the original `uploader_user_id` or a workspace `OWNER` (`403 DOCUMENT_DELETE_FORBIDDEN` for non-uploader members).
- **Transactional Outbox, Consumer Inbox & Deterministic Extraction/Chunking (`Day073` & `Day074`):**
  - Emits `document.ingestion.requested.v1` via `outbox_events` carrying only document/workspace IDs, revisions, and SHA-256 checksums (never raw text or embeddings).
  - Consumes events idempotently via `consumer_inbox` (`document-ingestion-inbox`) into `DOCUMENT_INGESTION` `work_items`.
  - Chunks text deterministically (`paragraph-window-v1`) and computes `384`-dimensional L2-normalized CPU embeddings (`pretrained-cpu-hash384-v1`) stored in `pgvector` (`vector(384)`) alongside PostgreSQL generated `tsvector` (`lexical_tsv`).
  - Explicitly labels `pretrained-cpu-hash384-v1` as an external/separate retrieval component distinct from the from-scratch `ScratchGPT` causal decoder.
- **Pre-Ranking Workspace-Filtered Search & Context-Budget Citations (`Day075`, `Day076` & `Day077`):**
  - Enforces workspace membership (`JOIN memberships`) and `ingestion_status = 'READY' AND deleted_at IS NULL` **inside** the PostgreSQL query before similarity ranking or `LIMIT`.
  - Packs retrieved evidence within the `ScratchGPT` `128`-token context window (`RunService.submitRun`), persists `retrieval_snapshots`, and emits `retrieval.context` SSE events (`sequence = 2`).
  - Validates citations server-side (`POST /api/v1/runs/{runId}/citations/validate`), rejecting model-invented citation IDs (`REJECTED_UNVERIFIED_CITATION`).
- **Independent Retrieval Evaluation & Adversarial/Tombstone Hardening (`Day078`, `Day079` & `Day080`):**
  - [`evals/retrieval/report.md`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/evals/retrieval/report.md) and [`evals/retrieval/results.json`](file:///e:/backend-java/3-projects/7-LLM/central/LLM-System-From-Scratch/evals/retrieval/results.json) record `Recall@1 = 1.0000`, `Recall@3 = 1.0000`, `MRR = 1.0000`, and `Unanswerable Abstention Rate = 1.0000` on the held-out `test` split.
  - Deletion sets a tombstone (`ingestion_status = 'DELETED', deleted_at = clock_timestamp()`) that prevents in-flight or late ingestion jobs from reactivating deleted sources and transitions historical run citations to `UNAVAILABLE_DELETED` in both REST responses and `ScratchLlmClient.format_citations_for_cli()`.
